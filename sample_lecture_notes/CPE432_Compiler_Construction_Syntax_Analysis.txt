# CPE 432: Compiler Construction & Language Design
## Topic: Syntax Analysis and Parsing Techniques

The syntax analyzer (parser) accepts a sequence of lexical tokens generated by the lexer and constructs a parse tree or Abstract Syntax Tree (AST) conforming to a Context-Free Grammar (CFG).

Grammar Representation:
G = (V_N, V_T, P, S) where V_N is non-terminals, V_T is terminals, P is production rules, and S is the start symbol.

Parsing Classifications:
1. Top-Down Parsing:
   - Starts at start symbol S and derives the target string (e.g. Recursive Descent, LL(1)).
   - Requires calculating FIRST and FOLLOW sets. A grammar is LL(1) if parsing table entries are unique (no left recursion or ambiguous productions).
2. Bottom-Up Parsing:
   - Starts at input tokens and reduces them towards start symbol S using shift-reduce actions (e.g. LR(0), SLR(1), LALR(1), canonical LR(1)).
   - Parser state machine tracks items [A -> alpha . beta, a] and resolves shift/reduce or reduce/reduce conflicts.
